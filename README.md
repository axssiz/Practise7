# Практическая работа: JavaScript

В этом проекте есть файл `practical_work.js` с решениями 30 заданий и веб-приложение `quiz_pm04_access.html` для тренажёра по вопросам ПМ04.

## Описание

### JavaScript задачи

В файле реализованы функции для:

- вычисления квадрата числа
- проверки деления на 3
- вычисления остатка от деления
- перевода Цельсия в Фаренгейты
- поиска максимального числа из трёх
- перевода строки в верхний регистр
- удаления пробелов из строки
- замены букв "a" на "o"
- подсчёта длины строки без `.length`
- проверки наличия подстроки
- суммы чётных чисел массива
- подсчёта элементов больше заданного числа
- удаления первого элемента массива
- добавления элемента в начало массива
- поиска максимального и минимального значения массива
- разворота массива вручную
- суммы элементов на чётных индексах
- создания копии массива
- проверки наличия элемента в массиве
- работы с объектом пользователя
- добавления и удаления свойств объекта
- простых действий с DOM: изменение цвета текста, скрытие элемента, показ значения input, добавление элемента в список, очистка поля ввода

### Веб-приложение тренажёра

### Веб-приложение тренажёра

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express, SQLite
- **Функции:** Генерация ключей доступа, управление пользователями, админ панель
- **Безопасность:** Один ключ действителен только на одном устройстве (привязка к сессии)

## Запуск

### JavaScript файл

```bash
node practical_work.js
```

### Веб-приложение

1. Установите зависимости:

```bash
npm install
```

2. Запустите сервер:

```bash
npm start
```

3. Откройте в браузере: `http://localhost:3000`

### Деплой

Для деплоя на сервер (Heroku, Railway, etc.):

1. Загрузите все файлы на GitHub
2. Подключите репозиторий к платформе деплоя
3. Установите переменную PORT (автоматически)
4. Приложение будет доступно по URL платформы

## Админ доступ

- Логин: admin123 (измените в админ панели)
- В админ панели можно генерировать ключи, управлять пользователями, менять пароль
